Heyo, thank you for checking out my bot!

This is a very dumb and simple telegram bot that I made to have people changing the wallpaper of one of my screen on Windows.
The bot only works on Windows, and I'll be honest, I don't remember what screens it displays it on, I coded this a LONG time, I remember it appearing on the my 3rd monitor only but eh.

It doesn't really come with any command, `/start` does relatively fuck all except explaining how the bot works, and `/ban` only allows the admin (Based off the ChatID set in the config file) to ban certain ChatIDs from using the bot in case of abuse.
The bot only applies wallpapers that are in .png, .jpg, .jpeg and .gif. Anything else goes to the bin.
Every time a wallpaper is applied, a watermark is set with the user's nickname and ChatID, so in case of abuse, the ChatID is *right there!*

The bot's probably unsafe as hell. God knows what kind of horrible code I wrote that warrants an update to the Geneva convention but, hey. T'was fun running it for a little while.

Have fun, and if there's any problem, please hesitate to contact me.
